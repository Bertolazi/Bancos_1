## Comandos da DML

- INSERT
    - Insere uma ou mais tuplas em uma tabela:
```SQL
-- Inserção de uma tupla
INSERT INTO tabela [(atrib_1, atrib_2, ...)]
    VALUES (valor_1, valor_2, ...) 

-- Inserção de múltiplas tuplas
INSERT INTO tabela [(atrib_1, atrib_2, ...)]
    <comando SELECT>
```
